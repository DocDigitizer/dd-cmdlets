DocDigitizer PowerShell Module

Installation Guide

Installation | Commands Reference | Scripting Examples

Requirements

  • PowerShell 5.1 or later (PowerShell 7+ recommended for better performance)
  • Network access to DocDigitizer API

Option 1: Import Directly from Folder

The simplest method - import the module directly from its location:

Import-Module "C:\path\to\Tools\DocDigitizer.PowerShell\DocDigitizer.psd1"

Option 2: Copy to PowerShell Modules Folder

Copy the module to your user modules folder for easier access:

# Copy to user modules folder
$modulePath = "$env:USERPROFILE\Documents\PowerShell\Modules\DocDigitizer"
Copy-Item -Path ".\Tools\DocDigitizer.PowerShell" -Destination $modulePath -Recurse

# Then import
Import-Module DocDigitizer

Option 3: Add to PSModulePath

Add the module location to your PowerShell module path:

$env:PSModulePath += ";C:\path\to\Tools\DocDigitizer.PowerShell"
Import-Module DocDigitizer

Verify Installation

After importing, verify the module is loaded:

# Check available commands
Get-Command -Module DocDigitizer

# Test connectivity
Test-DocDigitizerConnection

Configuration

The module comes pre-configured with default settings. You can customize using environment variables:

Variable Description Default
DOCDIGITIZER_URL API base URL https://apix.docdigitizer.com/sync
DOCDIGITIZER_APIKEY API key for authentication (built-in default)
DOCDIGITIZER_PIPELINE Default pipeline name (server default)
DOCDIGITIZER_LOGLEVEL Default log level Minimal
DOCDIGITIZER_TIMEOUT Request timeout (seconds) 300

Troubleshooting

Module Not Found

If you get "module not found" errors, ensure the path is correct:

# Check if the file exists
Test-Path "C:\path\to\DocDigitizer.psd1"

# Use the full path when importing
Import-Module "C:\full\path\to\DocDigitizer.psd1"

Connection Issues

# Test with verbose output
Test-DocDigitizerConnection -Verbose

# Check current configuration
Get-DocDigitizerConfig
