Before You Start

Make sure you have imported the module and set your API key:

Import-Module C:\Tools\dd-cmdlets\DocDigitizer.psd1
Set-DocDigitizerConfig -ApiKey "your-api-key-here"

Don't have an API key? Get one at customerportal.docdigitizer.com

Basic Examples

Process a single document

Send-DocDigitizerDocument -FilePath "C:\Documents\invoice.pdf"

This sends the PDF to DocDigitizer and returns the extracted data as JSON.

Process and save the result

Send-DocDigitizerDocument -FilePath "C:\Documents\invoice.pdf" -SaveExtraction

This creates invoice_extraction.json in the same folder as your PDF.

Save to a specific location

Send-DocDigitizerDocument -FilePath "C:\Documents\invoice.pdf" -OutputPath "C:\Results\my_result.json"

OCR-Only Processing

Use the OCROnlyPipeline to extract text from images and PDFs without data extraction.

Process an image file

# Process a PNG image
Send-DocDigitizerDocument -FilePath "C:\Documents\scan.png" -Pipeline "OCROnlyPipeline"

# Process a JPEG photo
Send-DocDigitizerDocument -FilePath "C:\Documents\photo.jpg" -Pipeline "OCROnlyPipeline" -SaveExtraction

Supported image types: JPEG, PNG, TIFF, BMP, WebP, GIF

Access OCR results

# Get OCR result
$json = Send-DocDigitizerDocument -FilePath "document.png" -Pipeline "OCROnlyPipeline"
$result = $json | ConvertFrom-Json

# Get the full extracted text
$result.output.documents[0].ocr.fullText

# Get individual words with positions
$result.output.documents[0].ocr.words

# Get text organized by lines
$result.output.documents[0].textLines.lines

# Get word count
$result.output.metadata.numberOfWords

Include raw data

By default, only essential fields are returned. Use -IncludeRawData to include all details:

# Include all raw data in the output
$json = Send-DocDigitizerDocument -FilePath "document.png" -Pipeline "OCROnlyPipeline" -IncludeRawData
$result = $json | ConvertFrom-Json

# Now you have access to:
$result.output.documents[0].ocr.words              # Words with bounding boxes
$result.output.documents[0].textLines.tokensByLine # Token mappings
$result.output.documents[0].rawOCRResponse         # Full Google Vision response
$result.output.documents[0].pageImageBase64        # Page image as base64

Process multiple images

# Process all images in a folder
Get-ChildItem "C:\Scans\*.png" | Send-DocDigitizerDocument -Pipeline "OCROnlyPipeline" -SaveExtraction

# Process mixed file types
Get-ChildItem "C:\Scans\*" -Include *.png,*.jpg,*.pdf | Send-DocDigitizerDocument -Pipeline "OCROnlyPipeline" -SaveExtraction

Processing Multiple Documents

Process all PDFs in a folder

Get-ChildItem "C:\Documents\*.pdf" | Send-DocDigitizerDocument -SaveExtraction

This processes every PDF and saves a JSON file for each one.

Process PDFs and keep them grouped

# Create a context ID to group documents together
$contextId = [guid]::NewGuid()

# Process all PDFs with the same context
Get-ChildItem "C:\Documents\*.pdf" | Send-DocDigitizerDocument -ContextId $contextId -SaveExtraction

Working with Results

Get result and convert to object

# Get JSON result
$json = Send-DocDigitizerDocument -FilePath "invoice.pdf"

# Convert to PowerShell object
$result = $json | ConvertFrom-Json

# View the trace ID
$result.traceId

# View extracted data (standard pipelines)
$result.output.extractions

# View OCR documents (OCROnlyPipeline)
$result.output.documents

# View processing times
$result.timers

Get more details in the response

# Minimal response (default) - just essential data
Send-DocDigitizerDocument -FilePath "invoice.pdf"

# Medium response - includes metadata
Send-DocDigitizerDocument -FilePath "invoice.pdf" -LogLevel Medium

# Full response - complete execution details
Send-DocDigitizerDocument -FilePath "invoice.pdf" -LogLevel Full

Error Handling

Check if processing succeeded

$result = Send-DocDigitizerDocument -FilePath "document.pdf" -ErrorAction SilentlyContinue

if ($result) {
    Write-Host "Success!"
} else {
    Write-Host "Processing failed"
}

Use try/catch for errors

try {
    $result = Send-DocDigitizerDocument -FilePath "document.pdf" -ErrorAction Stop
    Write-Host "Success! TraceId: $(($result | ConvertFrom-Json).traceId)"
} catch {
    Write-Host "Error: $($_.Exception.Message)"
}

Complete Scripts

Process all PDFs in a folder with error handling

# process_folder.ps1
# Usage: .\process_folder.ps1 -FolderPath "C:\Documents"

param(
    [string]$FolderPath = "."
)

# Import the module
Import-Module C:\Tools\dd-cmdlets\DocDigitizer.psd1

# Get all PDFs
$pdfs = Get-ChildItem "$FolderPath\*.pdf"
Write-Host "Found $($pdfs.Count) PDF files"

# Process each one
$success = 0
$failed = 0

foreach ($pdf in $pdfs) {
    Write-Host "Processing: $($pdf.Name)..." -NoNewline

    try {
        Send-DocDigitizerDocument -FilePath $pdf.FullName -SaveExtraction -ErrorAction Stop | Out-Null
        Write-Host " Done" -ForegroundColor Green
        $success++
    } catch {
        Write-Host " Failed: $($_.Exception.Message)" -ForegroundColor Red
        $failed++
    }
}

Write-Host ""
Write-Host "Complete! Success: $success, Failed: $failed"

Watch a folder for new PDFs

# watch_folder.ps1
# Processes new PDFs and moves them to a "Processed" folder
# Usage: .\watch_folder.ps1 -WatchFolder "C:\Incoming"

param(
    [string]$WatchFolder = "C:\Incoming",
    [string]$ProcessedFolder = "C:\Processed"
)

Import-Module C:\Tools\dd-cmdlets\DocDigitizer.psd1

# Create processed folder if it doesn't exist
if (-not (Test-Path $ProcessedFolder)) {
    New-Item -ItemType Directory -Path $ProcessedFolder | Out-Null
}

Write-Host "Watching $WatchFolder for new PDFs..."
Write-Host "Press Ctrl+C to stop"

while ($true) {
    $pdfs = Get-ChildItem "$WatchFolder\*.pdf" -ErrorAction SilentlyContinue

    foreach ($pdf in $pdfs) {
        Write-Host "Processing: $($pdf.Name)"

        try {
            Send-DocDigitizerDocument -FilePath $pdf.FullName -SaveExtraction -ErrorAction Stop | Out-Null
            Move-Item $pdf.FullName $ProcessedFolder -Force
            Write-Host "  Done - moved to $ProcessedFolder"
        } catch {
            Write-Host "  Failed: $($_.Exception.Message)" -ForegroundColor Red
        }
    }

    Start-Sleep -Seconds 5
}

Generate a processing report

# generate_report.ps1
# Processes PDFs and creates an HTML report
# Usage: .\generate_report.ps1 -FolderPath "C:\Documents"

param(
    [string]$FolderPath = "."
)

Import-Module C:\Tools\dd-cmdlets\DocDigitizer.psd1

$pdfs = Get-ChildItem "$FolderPath\*.pdf"
$results = @()

foreach ($pdf in $pdfs) {
    Write-Host "Processing: $($pdf.Name)"

    try {
        $json = Send-DocDigitizerDocument -FilePath $pdf.FullName -ErrorAction Stop
        $r = $json | ConvertFrom-Json

        $results += [PSCustomObject]@{
            File = $pdf.Name
            TraceId = $r.traceId
            State = $r.state
            Pages = $r.pageCount
            Status = "Success"
        }
    } catch {
        $results += [PSCustomObject]@{
            File = $pdf.Name
            TraceId = ""
            State = ""
            Pages = ""
            Status = "Failed: $($_.Exception.Message)"
        }
    }
}

# Create HTML report
$html = $results | ConvertTo-Html -Title "DocDigitizer Processing Report" -PreContent "
Processing Report
Generated: $(Get-Date)
"
$html | Out-File "processing_report.html"

Write-Host ""
Write-Host "Report saved to: processing_report.html"
